# 站外内容推广活动方案（小红书 / B站 / 微博 / 知乎）

> 站点：游戏源神 · `pan.devmini.space`（ECS 线 `mibear.top`）
> 活动承载：站内静态活动页 `activity.html` + 站外内容发布 + 站内提交审核
> 状态：方案稿（未落地）

---

## 0. 一句话结论：玩法必须换

**"把链接分享出去 → 截图 → 领奖励"这个玩法在这四个平台上不成立。**

- **小红书**：明令禁止站外导流。《社区规范》正文、图片、简介里出现**外链、二维码、手机号/微信号/QQ、第三方水印**都属于高风险行为，2026 年新规执行更严：轻则笔记不进推荐、账号降权，重则限流、禁言、封号。**用户拿不到你的链接，你也没法用"点击"验收。**
- **知乎**：回答/文章里的外链会被折叠或走跳转提示页，纯导流回答会被删。
- **B站**：简介/专栏能放链接，但引流外链容易被限流。
- **微博**：正文可以直接放 URL，是四个平台里唯一"放链接不算事"的。

→ 唯一可行的玩法是 **"内容种草 + 站名被搜索"**：用户发真实的游戏向内容，站名「游戏源神」自然出现在正文里，感兴趣的人**自己去搜站名**。
考核指标、奖励标准、提交材料，全都要跟着这个事实改。

## 1. 考核指标（先定这个，否则活动无法验收）

| 原设想 | 现实 | 替代指标 |
|---|---|---|
| 分享链接的点击数 | 四个平台里三个放不了链接 | ① **有效作品数** ② **站名搜索量**（百度统计「搜索词」报告） ③ **直接访问量** ④ **App 下载量** |

- `?ref=GH-XXXX` 专属链接只在**微博正文、B站简介、知乎个人简介**能放，只作辅助归因，**不能当主指标**。
- 活动开始前先把当前基线记下来（近 7 日直接访问数、App 下载数、站名搜索量），否则活动结束没有对照。

---

## 2. 平台 × 作品形态 × 硬性要求

| 平台 | 作品形态 | 能否放链接 | 内容禁区 | 硬性要求 |
|---|---|---|---|---|
| 小红书 | 图文笔记：标题 + 正文 + 3~9 张图 + 话题 | ❌ 严禁 | 外链 / 二维码 / 微信 QQ / 第三方水印；「资源下载」「破解」「网盘」 | 站名出现在正文；带 2~3 个游戏向话题 |
| B站 | 30~60s 视频 或 专栏文章 | ⚠️ 仅简介，易限流 | 纯资源搬运、无原创画面 | 有真实演示画面；站名在标题或简介 |
| 微博 | 图文微博 + 话题 | ✅ 正文可放 | 刷屏式纯广告 | 带话题；正文放专属链接 |
| 知乎 | 回答 / 文章 | ⚠️ 会被折叠 | 纯广告式回答 | 回答真实问题，200 字以上干货 |

## 3. 内容方向（决定会不会被删、被封号 —— 最关键的一节）

**绝对禁止**让用户发「游戏资源下载 / 网盘分享 / 破解版」这类内容。小红书和 B站对这类词极敏感，**用户账号会被限流甚至封**——封的是他的号，他会来找你算账，这是口碑反噬。

改走软内容，四个方向（每个方向都有真实需求）：

1. **省钱党**：「学生党玩游戏，我是怎么把预算压下来的」
2. **避坑**：「买游戏最容易踩的 5 个坑」
3. **盘点清单**：「10 个被低估的独立游戏」（站内正好有这些资源可引用）
4. **工具/教程**：「怎么整理自己的游戏库」/「怎么找回小时候玩过的老游戏」

站名只作为 **"我平时一般在 XX 上找"** 的顺带提及，不做主角。

**诚实性要求（既是伦理也是风控）**：让用户写自己真实的体验，不要给用户发"照抄模板编经历"的话术。有偿分享被同行举报一次，账号和活动一起完蛋。

## 4. 素材包（你出，不要让用户自己写）

用户写不出能过审的内容 —— 素材包是活动成败的一半。

- **4 套文案模板**（每平台一套，标题 + 正文 + 话题标签），站内活动页提供「一键复制」
- **主视觉图 1 张 + 长图 1 张**（放 `public/activity/`，站内提供下载）
- **统一话术**：站名「游戏源神」+ 一句话定位「全网游戏资源聚合 · 免费 · 持续更新」
- **口令** `#GH-XXXX`（站内生成，见 §5）

模板示例（可直接用的骨架）：

```
【小红书】
标题：学生党玩游戏，一年省了小两千的真实心得
正文：① 只买史低，打折季清单怎么列 ② 一大部分在游戏源神上找现成的，
      聚合得挺全不用自己到处翻 ③ 三张截图（我的游戏库/清单/游玩时长）
话题：#单机游戏 #游戏推荐 #学生党
⚠️ 不放链接、不放二维码、不加水印

【B站】
标题：我用一年时间整理了自己的游戏库，顺便算了下省了多少钱
形式：30~60s 录屏 + 字幕；简介放站名 + 专属链接（带 ?ref=）
⚠️ 别做纯资源搬运，要有自己的画面和讲解

【微博】
正文：盘点 10 个被低估的独立游戏（附图 4 张）…… 我一般在 游戏源神 上找
      完整清单：<专属链接>
话题：#游戏推荐# #单机游戏#

【知乎】
问题：有哪些值得推荐的免费游戏资源网站？
回答：先给 3 条"怎么判断一个资源站靠不靠谱"的干货判断标准，再自然提到站名
⚠️ 不要一上来就丢站名，会被折叠
```

## 5. 站内活动页结构（`activity.html`）

站点是 Vue 3 + Vite 的 MPA，新增一个 html 入口 + `src/entries/activity.js` 即可，与现有 7 个页面同构。

| 板块 | 内容 |

| 3. **口令生成器** | 点一下生成 `GH-7F3A`，写进文案；用于去重与归因 |
| 4. 素材下载 | 主视觉图 + 长图（`public/activity/`） |
| 5. 提交入口 | 跳 QQ 群 / 第三方表单（当前无后端，见 §10） |
| 6. 榜单 | 手工维护的 JSON，持续制造"活动还活着"的信号 |
| 7. 免责声明 | 链到 `disclaimer.html` |

## 6. 奖励设计

**阶梯三档**

| 档位 | 条件 | 奖励 |
|---|---|---|
| 基础 | 1 篇有效作品 | 通用码（人人相同，即时发放，不用等审核） |
| 进阶 | 3 个不同平台各 1 篇 | 专属码：优先求资源 × 1 |
| 榜奖 | 活动期最佳作品 / 带来最多访问 | 定制合集 / 长期「推广官」称号 |

**奖励物**（用你手上最稀缺的东西，别用钱）：优先求资源 > 你没有的资源 > 现成资源合集打包 > 活动专属解压码 > 站内称号。

**两条硬规则**

1. **两段发放防秒删**：发布后发一半，7 天后作品仍在再发另一半。
2. **禁止把奖励挂在点赞数 / 转发数上**：平台明令禁止诱导互动，而且这种指标必然被刷。奖励只挂「发帖」这一个动作。

**不用现金**：一牵扯钱就是纠纷、税务、职业羊毛党三重风险。

## 7. 审核与防刷

- 口令去重（一个口令一次）+ 图片哈希去重（一张图一次）
- 一人一平台一号；多号刷直接封口令
- 作品必须**公开可访问**且 **7 天不删**
- **抽查 10%**：内容平台的作品比无源截图好核验得多——看链接存在性、发布时间、账号历史是否正常
- 举报机制：盗图被举报 → 撤销奖励 + 封口令
- **不做公开作品墙**：既保护用户隐私（截图含昵称/头像/微信号），也避免站内出现"导流"证据链

**默认全自动通过，人工只处理抽查和举报** —— 人工审每一条，这活动活不过一周。

## 8. 追踪

- 口令 → 专属链接 `https://pan.devmini.space/?ref=GH-7F3A`，站内读 `?ref` 并上报百度统计
- 主指标：**站名搜索量**（百度统计搜索词报告）+ 直接访问 + App 下载
- **待实测**：百度统计免费版能否按 URL 参数归因。不能归因的话，专属链接这条退化，只能靠站名搜索 + 问卷自报。

## 9. 站内宣传位（全部是已有通道，按曝光量排序）

1. **App 推送**：`notify.json` 的 `tapUrl` 指向活动页（每天 13:00 / 20:00 各拉一次）。这是你唯一的**主动触达**，价值最高。改 `tapUrl` 只推本仓库、**不用重发 APK**。
2. **首页公告弹窗**：`site.json` 的 `announcementModal`——**必须递增 `version`**，否则老访客永远看不到。
3. **QQ 群 / Telegram 群公告**：已有自动发送脚本与每日任务口径。
4. **资源详情页低调入口**：人流最大，但**绝不能挡「一键免费获取」CTA**。

## 10. 提交方式与现实约束

站上**没有后端**：`Admin.vue` 是浏览器直连 `api.github.com` + 你自己的 token，没有数据库、没有用户体系。所以"截图上传到网站"需要一个接收端。

| 阶段 | 提交方式 | 成本 |
|---|---|---|
| 一（7~14 天验证） | 跳 **QQ 群** / 第三方表单（腾讯问卷、金数据） | 0 后端，当天能上 |
| 二（验证跑得动才做） | ECS 上加 `location` + 小上传端点，落盘 `/home/www/gamehub-uploads/`（**兄弟目录，否则下次 `rsync --delete` 抹掉**），Admin 加审核页 | 要防刷（大小/类型/频率）、管磁盘、处理内容风险 |

**别用 Cloudflare Worker 收图**：你用户在国内，CF 通道访问质量不行；`github.com:443` 在你这台 ECS 上实测也是时通时断。

## 12. 风险清单

1. **用户账号被限流/封号**（最现实的风险）：活动页必须写明"请遵守各平台规则，账号风险自负"，文案要软。
2. **版权投诉放大**：流量放大 = 投诉放大；活动页链 disclaimer；素材里**不要出现具体资源名**。
3. **平台判定"诱导分享/刷量"**：奖励只挂发帖动作，不挂互动数据。
4. **隐私**：截图含昵称/头像/微信号 → 只私密审核，不公开。
5. **微信生态**（非主战场，但转发会绕回）：不要在微信里做奖励承诺，诱导分享违规落在你的域名上。
